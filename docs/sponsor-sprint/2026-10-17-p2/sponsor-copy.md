# Sponsor integration description — factual draft

Silico's P2 component independently checks whether an experiment is complete and
whether its conclusions follow from its supplied evidence. Local Rust gates catch
missing scenarios, stale contexts, audience mismatches, and failed deterministic
checks before inference. Nemotron through Crusoe then reviews goal alignment,
assumptions, and conclusion support. Every accepted review binds the immutable
plan and full request and returns validated evidence references and targeted
repair requests.

The completed software fixture received a live Nemotron pass. A deliberately
unsupported causal/predictive claim was blocked by a second live review executed
inside the existing OpenShell sandbox through managed Crusoe inference, without
a provider key in the verifier process environment. Exact receipts and hashes are
in this packet. These are component checks on synthetic fixtures. P1 integration,
real population experiments, scientific validation, and deployment remain outside
this P2 branch. No submission has been sent.
