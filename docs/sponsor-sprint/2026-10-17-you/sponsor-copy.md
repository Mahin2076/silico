# Sponsor integration description

P2 uses You.com Search to retrieve relevant external sources for its independent
experiment review. Nemotron through Crusoe checks whether the experiment's
assumptions and conclusions faithfully use those sources, with validated pointers
to both the web evidence and the experiment. Source changes invalidate the exact
review binding. Search failures, missing citations, and local integrity failures
prevent completion rather than quietly dropping the research step.

The live positive check retrieved five AAPOR sources and returned a validated
Nemotron pass citing one of them. This demonstrates a working component on a
labeled software fixture, not scientific validation or end-to-end product readiness.
