# One-minute judging demo

Open https://silico-livid.vercel.app/demo and click **Play walkthrough**. This is a replay of recorded live evidence, costs no API credits, and does not depend on the local backend staying online.

- **0–10 seconds:** “Silico tests questions against a synthetic city. Our hackathon contribution is making completion an evidence-backed decision. Here we compare three lunch prices and require external evidence about whether the results support real pricing.”
- **10–20 seconds:** “Crusoe runs the simulation across 33 weighted archetypes representing 10,000 synthetic residents. All twelve deterministic checks pass.”
- **20–30 seconds:** “NVIDIA Nemotron still refuses completion: the required methodological evidence is missing.”
- **30–40 seconds:** “That objection triggers one You.com search. We save five source records and produce a cited assessment.”
- **40–50 seconds:** “The real run hit a transport failure and an invalid review. Both blocked completion. Two explicit retries reused saved work.”
- **50–60 seconds:** “A valid final review authorizes completion. We expose the trace and limitations. This proves the workflow; real-world prediction accuracy remains unvalidated.”

The original map and population engine predate this contribution. Do not claim autonomous recovery for the two explicit retries, or measured self-improvement on unseen tasks. Use the city view afterward for interactive residents; that live view currently requires the local backend and tunnel.
